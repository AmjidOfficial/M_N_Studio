## Data integrity
No service menu, prices, offers, reviews, or client portfolio items are prefilled. The owner adds approved content in the admin workspace. Editorial photographs are labelled as inspiration, not client work.

## Source structure
- public/index.html: customer-facing site
- public/theme.css: responsive luxury visual system
- public/app.js: navigation and WhatsApp enquiry
- public/dynamic.js: published database content
- public/admin.html and public/admin.js: owner control centre
- api/: public and admin-only API routes
- migrations/: PostgreSQL schema

The Hatchable project is deployed separately. It starts with private visibility. The owner must set project visibility to Public in Hatchable Settings before anonymous visitors can open the permanent URL.
